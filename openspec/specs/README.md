# Specs (current behaviour)

Each archived change merges its deltas into `openspec/specs/<capability>/spec.md` (`openspec archive <id> -y`), so this
folder describes what the server does *today*. Capabilities so far: affix-loot, bots, champions, character, companion, crafting,
dungeon-scaling, paragon, potions, professions, world-scaling (+ loot, loot-pet, loot-filter, economy as
their changes are archived). Owner playtests that can't finish a change live in `docs/OWNER-CHECKS.md` "Playtests".
