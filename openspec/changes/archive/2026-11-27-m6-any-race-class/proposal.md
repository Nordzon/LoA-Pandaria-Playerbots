# m6-any-race-class

## Why
SPEC 4.9: any race with any class (e.g. an Undead Monk, a Tauren Rogue, a Gnome Druid). Stock MoP allows 122 of the 165
race x class pairs; the owner wants all of them for a single-player ARPG where looks and class are a free choice.

## What changes
- **Server (SQL, generated by `sql/tools/gen_any_race_class.py`):** the 43 missing pairs get a start position (the race's
  own start; Death Knights the shared DK start), the class's action bar and start items from a reference race, per-level base
  stats (reference race's class stats + this race's racial difference, measured on warriors), and class skill/spell rows
  that carry race masks get the new races' bits.
- **Client patch:** `CharBaseInfo.dbc` rows for all 165 pairs (the creation screen enables a class button only for listed pairs).
- Out of scope: starting outfits for new pairs (`CharStartOutfit`; the character starts with the class's items, the creation
  screen may show a plain model), racial class quests.
