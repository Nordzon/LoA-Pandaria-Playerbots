# m6-start-quests: starting-zone quests for new race/class pairs

## Why
Owner 2026-11-27: a Night Elf Paladin (Nordana) saw no new quests in Shadowglen after "Demonic Thieves". The zone's chain runs
through class quests (a class sigil -> the class trainer -> "Priestess of the Moon") that exist only for Blizzard's Night Elf
classes. The same gap hits the other new pairs (m6-any-race-class): Northshire splits every step by class, Echo Isles runs its
whole chain at the class trainers, and so on.

## Scope
- New race/class pairs borrow the **Warrior's** class quests of their starting zone (`arpg_quest_proxy`, generated by
  `sql/tools/gen_start_quests.py`: 13 races, 105 rows). Exactly that race + class may take them (hook in
  `Player::SatisfyQuestClass`, so quest marks and lists are right too).
- Steps given or ended by a class trainer ask for a Warrior spell (Charge on a dummy, ...): they complete on accept, the player
  just walks there and hands them in. Other steps (kill worgs, ...) are played normally.
- Switch `Arpg.StartQuests.Enabled` (1). Original pairs are unchanged.

## Not in scope
Death Knight start (shared, its own chain). Class quests outside the starting area (level 10+ class trainer quests).
